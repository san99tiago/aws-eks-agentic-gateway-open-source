    Tipos de interaccion, de un vistazo
    
  
    
    
    LLM-GW
    POST /v1/chat/completions y GET /v1/models. Un endpoint OpenAI-compatible; el campo model decide el upstream. Bedrock, placeholders, modelos virtuales y self-hosted se invocan igual.
    
    
    MCP-GW
    /mcp federa un FastMCP dentro de EKS. /agentcore/mcp proxea un MCP server en AgentCore Runtime y exige un access token de Cognito, validado en el gateway y otra vez en AgentCore.
    
    
    Inference routing
    Los modelos gemma-3-4b-it y llama3.2 son AgentgatewayModel con provider: Custom hacia un InferencePool. El Endpoint Picker de llm-d escoge el pod (cola, KV cache) en la GPU g6.xlarge.
    
    
    Guardrails
    Un solo guardrail de Bedrock, dos mecanismos. Nativo en los modelos Bedrock (respuesta 200 con el mensaje del guardrail). Via ApplyGuardrail antes y despues del modelo en todo lo demas (HTTP 403).
